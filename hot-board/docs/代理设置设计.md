# 代理设置设计（2026-10-14）

## 需求（截图里的三条）

1. **默认自动读取 Windows 系统代理**，换端口 / 换软件自动跟着变。
2. **设置面板手动覆盖**：代理地址输入框，保存到本地配置文件，重启保留。
3. **只对需要的源走代理**：Google Trends / Google News 走代理，国内源 + Hacker News 直连。每个源一个「使用代理」开关。

## 实现分层

```
┌──────────────────────────────────────────────────────────────────────┐
│ 前端 SettingsPanel.tsx                                              │
│  - 全局模式：Auto / Manual / Off                                     │
│  - 代理地址输入（Manual 时）                                          │
│  - 每个源的独立下拉：Auto / Proxy / Direct                           │
├──────────────────────────────────────────────────────────────────────┤
│ 后端 get_settings / set_settings 命令                               │
├──────────────────────────────────────────────────────────────────────┤
│ AppState                                                            │
│  - http:            直连客户端                                        │
│  - proxy_http:      系统代理客户端（启动时构建一次）                    │
│  - manual_http:     手动代理客户端（运行时热重建）                      │
│  - proxy_state:     当前 ProxySettings 快照                          │
├──────────────────────────────────────────────────────────────────────┤
│ proxy.rs                                                            │
│  - detect_system_proxy()：WinHTTP → WinINET → 环境变量                │
│  - ProxySettings 持久化到 %APPDATA%\...\proxy_config.json             │
│  - ProxySettings.use_proxy(id, server_default)：合并三层             │
└──────────────────────────────────────────────────────────────────────┘
```

## 三层优先级

1. 全局 `setting == Off`         → 一律直连
2. 用户手动覆盖 `source_modes[id]` → 用用户值
3. 云端 boards.json 默认 `source_mode[id]`（`useProxy` 字段）
4. 全局 `setting`：`Manual` 走 `proxy_url`，`Auto` 跟随 Windows 系统代理

## 云端 boards.json 里怎么标默认

```json
{ "id": "google_trends", "useProxy": true, ... }     // 走代理
{ "id": "weibo",         "useProxy": false, ... }    // 直连
```

也兼容字符串：`"sourceMode": "proxy" | "direct" | "auto"`。

## 设置持久化位置

`%APPDATA%\com.tauri-app.hot-board\proxy_config.json`

```json
{
  "setting": "auto",
  "proxyUrl": null,
  "sourceModes": {
    "weibo": "direct"
  }
}
```

## 单元测试

`cargo test --lib proxy` → 12 通过：

- 默认 Auto
- Manual 时 Auto 源走代理
- 源级 Direct 覆盖全局 Manual
- 全局 Off 优先级最高
- 源级 Proxy 覆盖云端 Direct
- 云端 Direct + 全局 Auto + 无用户覆盖 → 直连
- 云端 Proxy + 全局 Auto → 走代理
- `build_proxy_url` 各种输入格式
